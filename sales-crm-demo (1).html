Activity Log Setup

Add a second sheet called "Activity Log" to each salesperson's tracker file. The Apps Script v4 reads it automatically.

Sheet 2 — Activity Log columns:
Column A: Date (dd-mmm-yy format)  ·  Column B: Lead Name (must match Sheet 1)  ·  Column C: Activity Type (Call Answered / Call Unanswered / Field Meeting / Virtual Meeting)  ·  Column D: Notes (optional)

How to Set Up (5 minutes)

Each salesperson keeps their own Lead Tracker file in a shared Drive folder.

1
Create a shared Google Drive folder. Name files: FirstName_LastName_-_Lead_Tracker.xlsx
2
Each file has two sheets: Sheet 1 (Lead Tracker) and Sheet 2 (Activity Log).
3
Go to script.google.com, paste appscript-code4.js contents.
4
Deploy → New Deployment. Type: Web App. Execute as: Me. Access: Anyone. Authorize.
5
Paste Web App URL + Folder URL above, click Save, then Fetch from Drive.
